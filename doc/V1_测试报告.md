## 数据正确性检查

- 箱线图分位数与直方图分箱由服务端计算，包含全部符合筛选条件的数据。
- 直方图保留空分箱。
- 大整数标识符、前导零、混合字符串列和手动字符串类型保留原文。
- Excel 日期与布尔值保留类型；没有缓存结果的公式明确报错。
- 空值、空字符串和数值 0 分开处理；格式设置不修改 Snapshot。
- 第二指标参加同一服务端聚合。
- 保存过程中继续编辑时仍显示未保存；重复保存创建受到保护。
- 瀑布图正负累计跨过零点的坐标已覆盖回归测试。
- 不同数据集使用整体筛选时，仅应用包含同名字段的条件；界面已说明此规则。

## 可复跑命令

```powershell
.\.venv\Scripts\python.exe -m pytest backend/tests -q
cd frontend
npm test -- --run
npm run build
```

浏览器脚本：`tests/browser_workflow.py`、`tests/browser_imports.py`、`tests/browser_chart_catalog.py`、`tests/browser_grid_mapping.py`。需要 Playwright 的 Chromium；本机测试浏览器位于临时目录 `mybi-playwright`，运行时设置 `PLAYWRIGHT_BROWSERS_PATH` 指向它。

## 验证边界

Docker 和独立 PostgreSQL 部署尚未实机运行，本机入口使用 SQLAlchemy + SQLite 元数据及 Parquet Snapshot。数据库在线连接、SQL 编辑执行和任务调度属于后续版本。

本版本没有做千万行或压力测试。默认单文件 100 MB，其他资源限制见 README。
