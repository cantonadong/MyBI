# MyBI 通用 UI / UE 规范

依据“报表”列表页和“设置”页的现有视觉与布局整理。新页面、新功能先复用这里列出的类名、组件和交互；确实没有可复用的，再按同样的令牌扩展，并把新的通用写法补进本文档。

## 1. 原则

- **复用优先**：先找现有组件 / 类名（见第 4、5 节），不要为单个功能新写一套按钮、表格、弹窗或颜色。
- **不新增视觉令牌**：颜色、字号、圆角、间距、阴影只用第 2 节的取值；需要强调色时用 `var(--ui-accent)` 等变量，不写新的十六进制色。
- **紧凑**：全局基准字号 12px，控件高约 28px；按钮宽度跟随文字，不拉伸铺满。
- **中英双语**：所有新界面文字走 `t()`，并在 `frontend/src/locales/en.json` 补英文；用户数据、字段名、报表标题不翻译。

## 3. 页面布局

### 3.1 应用框架
- `.app-shell` 网格：左侧导航 `.rail` → 工具栏 → 画布 `.workspace` → 属性栏 `.properties`。
- 术语：第二栏叫“工具栏”，右侧栏叫“属性栏”。
- **新的一级功能**（如数据集、报表、定时任务）：
  1. 在 `.rail` 加按钮（`<Icon>` 图标 + 文字，选中加 `rail-active`），设置按钮始终在最底部；
  2. 用 `panel` / 路由显示独立页面，并在 `restoreRoute`、`activePath` 和后端 `main.py` 的页面路由里登记路径；
  3. 页面容器用 `<main className="reports-page dataset-management">`，外壳类 `datasets-open`（只保留导航栏和页面区）。
- 只属于偏好 / 配置的内容放进“设置”，不要占一级导航。

### 3.2 列表页（参照“报表”“数据集”“定时任务”）
- 页面：`.reports-page`，内边距 `20px 24px`，背景 `#f4f6fa`。
- 页头：`<header className="reports-heading"><h2>标题</h2><button className="primary">新建</button></header>`，h2 为 20px，主操作放在右侧。
- 表格：`<table className="reports-table">`，白底 + 1px 边框，单元格内边距 `10px 17px`，字号 12px。
  - 名称列用 `<button className="report-name">`，悬停变强调色；
  - ID 列只显示自增 ID（接口字段 `local_id`，`td.report-id`），不显示 UUID / 指纹；“复制 ID”复制的也是自增 ID。每类实体（数据集、报表、定时任务、Portal、用户、角色…）各自从 1 开始编号（`resource_identities.number`），新实体类型直接调用 `resource_identity(kind, …)` 即可获得编号；
  - 操作列用 `<div className="report-actions">`，每个按钮等宽对齐（列表页 88px），且都带 15px 图标；删除按钮加 `report-delete`（红字）；表格加一个页面专属类并设置 `--actions-width`（= 按钮数 × 88 + 间隔 × 8），让“操作”标题与右对齐的按钮组左边缘对齐，最后一列宽度 ≥ 该值 + 34px；
  - 空状态：`<td colSpan={列数} className="reports-empty">暂无…</td>`（高 120px，居中，次要文字色）。
- 分页：所有数据列表用 `<Pagination>`，每页 10 行，放在表格下方并水平居中（`.reports-page .table-pagination`，无论嵌套多深）。
- 筛选器、图表标题、默认名称等画布内容跟随画布界面语言；筛选器选中值默认不写进图表标题，需在筛选器属性中开启“应用到图表标题”。

### 3.3 设置页
- `.settings-page`：两列网格，左侧 160px 的 `.settings-nav` + 右侧最宽 640px 的内容区，间距 24px。
- 导航项：`<a>` + `aria-current="location"` 表示当前项（悬停 / 选中：`--ui-hover` 底 + 强调色字，选中加粗）。
- 每个分区一张 `.settings-card`：白底、1px 边框、9px 圆角、16px 内边距，标题 `h3` 13px；多张卡片之间 16px。
- 页头 `.settings-heading`：h2 20px + 右侧“返回画布”次按钮。

### 3.4 属性栏（画布右侧）
- 分组用 `<fieldset className="axis-settings"><legend>…</legend>`（7px 圆角、10px 内边距、legend 12px `#697286`）。
- 标签 11px `#697286`，输入框 / 下拉占满宽度，组间距 14px。

## 4. 控件

| 控件 | 规则 |
| --- | --- |
| 普通按钮 | 默认 `button` 样式：白底、`--ui-border` 边框、5px 圆角、12px；悬停边框 `#aebbf2`；禁用 `opacity: .5` |
| 主按钮 | `className="primary"`：强调色底白字，`6px 10px`，6px 圆角；每个区域最多一个 |
| 危险操作 | 文字按钮加 `report-delete`（红字），并且必须二次确认（第 5 节） |
| 图标按钮 | 用 `<Icon name=…>`（24 网格、1.7 线宽描边），同时提供 `aria-label` 和 `title` |
| 悬停菜单 | 参照“发布”按钮的 `.publish-menu`：悬停 / 聚焦展开，样式同 `.dataset-options` |
| 输入框 / 下拉 | 高 28px，`5px 8px`，`--ui-border` 边框，`--ui-radius` 圆角，聚焦按第 2 节 |
| 可搜索下拉 | 用 `<SearchSelect>`；时区一律用 `<TimezoneSelect>`，默认值 `localTimeZone()` |
| 复选框 | 原生 checkbox，`accent-color: #5264f6`，文字在右侧 |
| 开关 | 列表行内的启用/停用用 `.toggle-switch` 滑块（放在操作列最前），不用复选框 |
| 时间 | 一律用 `<TimePicker>`：24 小时制，点击展开时 / 分两列列表，鼠标滚轮或方向键分别调整 HH（00–23 循环）和 MM（00/10/15/20/30/40/45/50 循环）；不用原生 `type="time"`；定时类默认时间用 `defaultScheduleTime()`（UTC 0 点折算到用户时区，如 UTC+13 → 13:00），时区默认 `localTimeZone()`；展示用 `formatUpdatedAt()`，耗时用 `queryDuration()` |
| 数值显示 | 只是显示设置：整数 0 位，小数 1–8 位，百分比不改变原始值和计算精度 |

## 5. 反馈与交互

- **Toast**：调用 `setMessage(text)` / `onMessage(text)`，统一由 `.workbench-message` 显示，3 秒内淡出（`toast-lifetime`）；不要再写新的提示条。
- **行内错误**：`<p role="alert" className="source-error">`；**说明文字**：`<p className="source-hint">`。
- **进行中**：按钮内显示 `<span className="busy-spinner" />` + “处理中… / 查询中… / 执行中…”，同时禁用相关控件，防止重复提交。
- **确认**：一律用 `await confirmAction(t('…'))`（`.modal.report-confirmation`，取消在左、确认为主按钮在右）；不要用 `window.confirm`。删除、覆盖、放弃未保存修改必须确认。
- **弹窗**：`<dialog className="modal">`，标题 h2，底部 `.modal-actions` 右对齐（取消 → 主操作）。全局已支持 Y / N / Enter 快捷键，弹窗按钮保持这个结构即可生效。
- **空状态 / 加载**：列表空时用 `reports-empty`；图表区用 `.tile-error` 文案（如“加载中…”“没有符合筛选条件的数据”）。
- **筛选**：只通过工具栏添加的画布筛选器控制；只能用文本或日期维度，不能用数值字段。日期范围筛选器的日期框宽度只够显示 yyyy-mm-dd + 日历图标，不提供“清空筛选”按钮。筛选器最窄为画布 1/4；自动宽度的筛选器保持默认高度（`FILTER_DEFAULT_ROWS`）。
- **画布拖拽**：拖拽中的占位符（`.drag-slot`）为高亮色虚线边框，位于所有组件下方，不遮挡图表。被拖拽组件本身只显示占位符；其原位置的占位边界（`.drag-origin`）在整个拖拽过程中一直显示、松手才消失，且不参与交互（指针在原位置上时不预览任何插入，松手布局不变）；松手前只有目标行的其他组件做让位预览，其余行不动。目标组件按对角线分区：左 / 右三角（共 50%）为左右布局，该行组件让位，占位符按一行组件数显示为 1/2、1/3 或 1/4 宽（该行仍有 ≥1/4 空位时保留用户设定的宽度）；上 / 下三角显示该行上方 / 下方留白处的插入高亮线（`.insertion-line`）。命中判断按组件原始网格位置计算，预览让位不会改变目标。
- **行内空位**：指针位于某行的空白处、且该空位宽度足够放下被拖组件时，按组件自身宽度在该空位显示预计松手位置的高亮边框（以指针为中心，限制在空位内）；筛选器与图表仍不同行，一行最多 4 个。
- **最小宽度**：所有组件（筛选器、图表）最窄为画布 1/4（`minWidth(columns)`），缩放、自动宽度、新建和左右插入都遵守；打开报表时，以前保存得更窄的组件会自动加宽到 1/4，被挤到的组件下移。
- **发布页居中**：发布页按编辑画布宽度居中显示。编辑器发布用当前画布宽度；报表列表发布用报表保存时记录的画布宽度（`document.canvasWidth`），没有记录时用本机上次的编辑画布宽度，不能拉满全宽。
- **参考线**：整体设置里“显示参考线”开关 + “参考线类型”二选一：4 分线（1/4、1/2、3/4）或 3 分线（1/3、2/3），默认 4 分线；线画在列间隙中线上，与缩放吸附宽度对齐。
- **缩放**：图表宽度在 1/4、1/3、1/2、2/3、3/4 附近吸附；用户缩窄后的图表保持宽度，可再拖入其他图表摆放到同一行，不会被自动拉满整行。

## 6. 文案

- 语言分两类：**软件界面语言**（`t()` / `useLanguage`：所有操作界面）和**画布界面语言**（`chartT()` / `useChartLanguage`：图表、筛选器等终端用户可见内容）。发布页和导出页整页使用发布时的画布语言。

- 简体中文为源文案，句末不加多余空格；英文在 `en.json` 中对应。
- 功能名保持一致：数据集、报表、定时任务、设置、工具栏、属性栏、筛选器、发布、发布为页面。
- 错误信息说清原因和下一步（例如“报表已被其他操作修改，请重新打开后再保存”）。
