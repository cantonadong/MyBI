# 数据集字段类型编辑

用户要求：导入后点击数据集仍可修改字段类型；预览中每列可独立编辑；点击弹窗外部不能关闭；提供保存、取消，× 等同取消。

方案：沿用 DatasetPreview 和导入已有的 string、number、boolean、date、datetime 转换规则。类型与展示格式均在弹窗内暂存，点击保存后一次提交。取消、×、Esc 放弃全部未保存修改，外部点击无效。保存期间禁止重复提交及关闭；失败保留编辑内容并提示。

保存会校验完整数据，而非仅预览十行；任何转换失败均拒绝整次保存，原数据保持完整。后端复用现有快照机制和版本检查，成功后更新数据集元数据。前端继续使用现有数据集入口和回调，不新增依赖。

方案取舍：逐字段即时保存无法满足取消语义，因此采用统一提交；只修改类型标签会使后续查询与真实数据不一致，因此执行实际转换。

验证：覆盖各类型转换、非法值拒绝、版本冲突，以及前端单独编辑每列、保存、取消、×、外部点击行为；运行相关测试及前端构建。
