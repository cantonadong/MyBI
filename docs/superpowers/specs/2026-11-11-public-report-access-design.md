# 已发布报表的 IP 与域名访问

目标：MyBI 运行期间，访客通过本机可达的 IP 地址查看已发布报表；支持预先配置域名。

## 方案

- 采用直接 IP / 域名访问，按用户选择不接入第三方隧道。
- 临时隧道需要外部服务且地址会变化；固定域名隧道需要账号与域名，本次不采用。

## 行为与边界

- 本地管理服务继续使用 127.0.0.1:8000。
- 增加独立的只读服务，默认端口 8001，启用时监听所有网络接口；与 MyBI 一起启动和停止。
- 在现有设置页添加服务开关、端口、可选域名（允许 http / https）、自动识别的公网 IPv4 及运行状态。配置保存在本机。
- 报表发布后可复制查看链接；域名为空时使用自动识别的公网 IPv4 与监听端口。通过 HTTPS 请求 ipify 获取出口地址，校验返回值，短期缓存并提供重新识别操作；识别失败时明确提示，不使用本地私网地址冒充公网地址。
- 公网入口只提供已发布报表页面、必要静态资源和报表范围内的数据读取接口；保留筛选、翻页和动态数据更新。
- 服务端校验报表已发布、数据集及快照属于该发布报表；拒绝管理接口、任意数据集访问和所有修改操作。
- 公网查看页不显示编辑、管理或评论操作。持有报表链接的访客可查看报表，无需登录。
- 域名设置用于生成链接，不会自动注册域名、修改 DNS 或签发证书。HTTPS 由后续反向代理提供，直接 IP 访问先用 HTTP。
- 公网访问需要可入站的公网 IP、路由器端口转发（如有 NAT）及防火墙放行；软件不能绕过运营商 CGNAT。

## 涉及范围

后端只读入口与配置接口、现有报表数据读取逻辑、前端设置及发布链接、共享中英文本地化、桌面服务生命周期与现有构建打包流程。保留工作区已有修改。

## 验证

按用户要求不运行测试。完成后执行构建，覆盖现有 MyBI.exe 并重启供用户验证 IP 访问；没有域名时仅检查域名配置与链接生成，不能宣称真实域名访问已验证。
